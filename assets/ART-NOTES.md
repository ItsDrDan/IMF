# Sticky Molecules — Round 2 Artwork (individual vector redraws)

These are **individually drawn and rendered SVG vector illustrations**, with each full-size source
rendered at 1024 × 1024 pixels. No image was enlarged or cropped from a combined sticker sheet.

## Package layout
- `logo.png` — 512×512 game logo; `imf.webp` — 512×512 study hub logo
- `logo-full.png` — native-rendered 1024×1024 logo image
- `mascot-*.png` — seven transparent Ollie expressions, each 1024×1024
- `*.png` — fifteen independent 1024×1024 badges with complete gold/navy rings
- `badges-webp-256/` — fifteen 256×256 WebP badges
- `source-svg/` — editable vector originals, useful for adjusting precise diagram geometry

## Chemistry notes
- Every Ollie uses symmetric, bent H–O–H geometry with four lone-pair dots grouped as two pairs.
- Hydrogen bonds are dashed, unlike covalent bonds, which are solid.
- `dipole-duo.png` intentionally has no dashed line or covalent bond between the molecules.
- `hbond-hero.png` depicts four neighbors around the central molecule.
- Ion Hugger depicts a cation with water oxygen ends facing it.
- The molecule characters are schematic; use textbook-precise structural drawings for formal assessment.

## Quality notes
This is a hand-authored vector redraw in the same *general* navy/pastel/gold style as the
art brief, not an individually painted AI illustration in the exact appearance of the first image.
Because the artwork is vector based, Claude can edit the geometry directly via SVG files.
